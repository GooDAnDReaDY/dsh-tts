# dsh-tts

Text-to-speech plugin for the DeepSeek Harness Web UI. Speaks finished agent replies through a provider fallback chain (7 cloud + 3 local providers). Published on npm as @goodandready/dsh-tts.

- Status: active, v0.3.1 (npm latest = tag v0.3.1)
- Install: dsh plugin --profile web add @goodandready/dsh-tts
- Tests: node --test test/*.test.mjs
