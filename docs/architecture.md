# Архитектура dsh-tts

## Обзор компонентов

Плагин реализует потоковую генерацию речи для DeepSeek Harness и состоит из двух частей:

1. **Серверный слой (Node.js / Cordis)**:
   - Слушает события `session/event` (assistant/message, turn/end, approval/asked).
   - Предоставляет инструмент `speak_text` для ручного вызова субагентами.
   - Подготавливает текст через `prepareSpeechText` (фильтры, правила произношения, авто-саммари).
   - Организует многоуровневую цепочку провайдеров (`chain`) с переключением на резервный в случае сбоя.
   - Кеширует синтезированное аудио на диске с защитой от race condition и дедупликацией in-flight запросов.
   - Транслирует аудиособытия через SSE-канал (`/dsh-tts/stream`) с контролем backpressure.

2. **Клиентский слой (React / Web Audio)**:
   - Встраивается в интерфейс настроек DSH (row seat `plugins.row.config`).
   - Подключается к SSE-потоку сервера и воспроизводит аудио через очередь с предбуферизацией.
   - Обрабатывает блокировку autoplay браузером и предоставляет интерфейс разблокировки.
   - Поддерживает перебивание голосом (barge-in) и регулировку темпа воспроизведения.
